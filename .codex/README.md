# Red Panda Academy Context

This folder is the working handoff for AI-assisted implementation. It keeps both the frontend migration context and the backend architecture context in one place so the project can move from analysis to implementation without losing decisions.

Start with:

- `project-context.md` for the frontend product, current architecture, and migration invariants.
- `implementation-plan.md` for the staged React conversion sequence.
- `migration-rules.md` for compatibility rules that should not drift.
- `backend-context.md` for the Django backend scope, role model, and player-first API direction.
- `backend-plan.md` for the staged backend implementation sequence.

The old `plans/` folder is preserved as received. These `.codex` files are the maintained implementation context going forward.
